**Motekeeper — Relight the Gloaming.** A top-down arena game in plain HTML5 canvas JavaScript, drawn and sounded entirely in code (no image or audio assets). You are the lantern keeper of a night whose five dawn anchors have been snuffed by hollow shards. Gather light motes to build combo chains and relight the anchors one by one; banish drifters, weavers and brutes with your pulse of light; dash through danger; grab hearts and Overglow stars. Light all five anchors to break the dawn — or fall, and the night prevails. WASD/arrows or mouse to steer, Space to pulse, Shift to dash, P to pause, M to mute. The simulation is a fixed-step, seeded world, so every run can be replayed exactly.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
